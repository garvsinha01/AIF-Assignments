# Graph Search Algorithms in Python

A program that demonstrates **DFS**, **BFS**, and **A*** search on a graph.

## Features

* Depth First Search (DFS)
* Breadth First Search (BFS)
* A* Search with heuristic values

## Concepts Used

* Graphs
* Queue (`deque`)
* Priority Queue (`heapq`)
* Heuristic Function

## Output

Displays the traversal order of DFS, BFS, and A* search.
